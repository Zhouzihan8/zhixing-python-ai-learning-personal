# 个人学习站自动同步与个性化建议

## 意图

让学习者照常打开收藏的 GitHub Pages 网址时，学习记录助手已在本机运行，网页能自动读取本机进度；推荐内容继续依据学习者真实记录调整。

## 目标与边界

- Windows 登录时启动现有回环地址助手；用户仍可用浏览器收藏打开稳定网址。
- 课程资源加载后自动尝试连接 `127.0.0.1:19868` 并读取学习进度。连接失败不阻止课程、讲义或练习使用，也保留手动重连。
- 个性化依据只使用明确记录的课程状态、提示使用情况、卡点和补练次数；不声称自动理解自由文本或推断掌握程度。
- 用过部分或完整提示时，推荐先合上答案独立重做；同一内容多次需补练时，推荐拆成预测、运行、解释的小步骤。
- 继续按 C/C++ 已学、Python 入门、大学数学已学、大模型科研为目标的起点组织路线；数据库和后端在项目确实需要时衔接，不安排固定日历复习。
- 学习记录留在 `D:\学习\个人学习\00_学习管理`，不进入 GitHub 仓库；原本地网站和公开课程站不改。

## 方案比较

1. 让托管网页直接启动本机进程：浏览器安全机制不允许，排除。
2. 点击本机“开始学习”快捷方式时启动助手并打开网页：不常驻，但需要改用快捷方式进入。
3. Windows 登录时启动助手，打开收藏网址时网页自动同步：占用一个轻量本机进程，但保留学习者习惯的稳定网址入口。

采用方案 3，因为学习者明确希望照常打开收藏网址并自动同步。站点不会获得启动其他本机程序的权限。

## 实现与验收

- 使用 Windows 当前用户的启动文件夹快捷方式启动助手，不配置系统服务或管理员任务。
- 网页仅在课程脚本加载后尝试一次本机连接；助手不可用时呈现可恢复状态，不循环请求。
- 网站端与本机 Markdown 摘要端的建议规则保持一致；用提示和重复补练记录会改变下一步建议。
- 验收：助手能在当前 Windows 登录会话中启动；网页能自动读取既有本机进度；助手关闭或本机权限被拒绝时课程仍能打开、手动重连提示正确；学习记录文件仍只在本机。
