# 学习进度同步实现计划

## 目标

让个人 GitHub Pages 学习站根据本人明确提交的学习记录提示下一步，并把记录保存在本机 `个人学习/00_学习管理`。学习时长、打开网页或运行成功都不自动代表掌握。

## 设计边界

- 只更新个人版仓库；本机学习站和公开课程版保持不变。
- Pages 仍为静态站；本机 Python 标准库助手绑定 `127.0.0.1`，不监听局域网、不接收任意路径。
- 学习记录只写入本机 JSON 和《学习进度.md》，不提交到 GitHub。
- 用户点击连接或记录按钮后才访问本机助手；连接失败时课程仍可正常浏览。
- 状态按实际记录调整：需补练优先、学习中继续、独立完成后进入下一项、后续任务中有明确复用证据才标记稳定掌握。

## 实施步骤

1. 为课程页增加连接、记录、状态展示与知识树进度推荐；核对只在用户操作后请求本机服务。
2. 在 `个人学习/00_学习管理/进度同步助手` 提供无第三方依赖的本机助手、启动脚本和使用说明；助手只写其固定目录内的两个进度文件。
3. 更新个人站点 README，说明首次连接授权、启动方式、记录的本机边界和无法连接时的降级行为。
4. 将仅含站点代码与说明的变更发布到个人 GitHub Pages；不上传本机学习记录或助手运行数据。

## 完成判据

- 课程状态可经用户明确操作记录；继续、补练、初步掌握、稳定掌握语义有证据约束。
- 知识树能按真实记录给出当前建议；本机 Markdown 和 JSON 由助手更新。
- 助手仅监听回环地址，只接受个人站点 Origin 与已知课程编号。
- 发布变更仅落在个人版仓库，两个既有站点不变。
